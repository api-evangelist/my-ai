# My AI / Me Protocol

> My AI Inc. is the company behind Me Protocol, a universal open rewards infrastructure that lets brands issue, redeem, and swap loyalty rewards across a decentralized cross-brand ecosystem through a single API integration. It combines an EVM smart-contract layer (Sepolia, Hedera, Base, Polygon), a hosted Platform-as-a-Service REST API, and embeddable SDKs for web and AI-agent storefronts. Founded 2022 by Robert Wesley and Paul Oamen; backed by 500 Global.

## APIs

- [Me Protocol PaaS API](https://me-api-docs.pages.dev/): Hosted REST API (base https://paas.memarketplace.io/v1/api/) authenticating SDK integrations with a brand API key and brokering reward issuance, redemption, and cross-brand token swaps.
